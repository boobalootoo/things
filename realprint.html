Help & Documentation

How to use this site

  • Step 1: Select a high-resolution image from your device.
  • Step 2: Enter the physical size you want the image to be when printed.
  • Step 3: Use the Zoom slider in the sidebar to see your whole poster if it is very large.
  • Step 4: Click "Add A4 Tile". Hover over a tile to see Rotate (landscape/portrait) and Delete options.
  • Step 5: Click "Export PDF". The app creates a PDF where each page matches the orientation of its respective tile.

GitHub Pages Hosting

To host this on GitHub pages, simply upload this `index.html` file to a repository and enable "Pages" in the settings. This tool is client-side only; no data leaves your browser.
