Project Setup & Hosting

How to Host on GitHub Pages

  1. Create a new repository on GitHub (e.g., dobble-game).
  2. Upload this index.html file to the root.
  3. Go to Settings > Pages.
  4. Under "Branch", select main and click Save.
  5. Your site will be live at https://yourusername.github.io/dobble-game/
