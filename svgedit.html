SVG Craft Pro Guide

Tools & Elements

We've added Ellipse, Polygons, and Text. Click the text tool, then click the canvas to start typing. For Polygons, drag to size them.

Import & Control

Use the Import button to upload any .svg file. Every single path, rectangle, and group inside the file becomes selectable and editable within the tool.

GitHub Pages Deployment

  2. Upload this index.html.
  3. Enable Settings > Pages.
