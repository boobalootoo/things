Which format is best?

  • PNG: Best for text-heavy PDFs and diagrams. Preserves sharp edges without artifacts. Supports transparent backgrounds. (Larger file size)
  • JPEG: Best if your PDF is mostly photographs. Does NOT support transparency (background will default to white). Can cause slight blurring around small text. (Smallest file size)
  • WebP: The modern web standard. Offers high quality like PNG but at a much smaller file size. Supports transparency. Best for using the result on a website.
