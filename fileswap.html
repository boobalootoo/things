How to use this site

1. Quick Code Paste

Need a quick HTML or text file? Paste your code into the text area on the left, select your desired extension, and click download. It runs entirely locally.

2. Bulk File Converter

Drag and drop multiple files to convert them. You can manage conversions in two ways:

  • By Item: See a list of your files. For each file, open the dropdown to select multiple target formats you want it converted into.
  • By Format: Select a target format first (e.g., PDF). The list will filter to show only files that can be turned into a PDF. Check the ones you want to convert.

3. GitHub Pages & Local Processing Note

This site is designed to run statically on GitHub Pages. Text/Code conversions and Image format conversions (PNG, JPG, WEBP via HTML Canvas) are processed natively in your browser.

Note: Complex transcoding (like Video to MP3, or DOCX to PDF) typically requires heavy backend servers. In this static version, selecting these will demonstrate the UI capability and output structural files, but genuine media transcoding requires server-side integration.
