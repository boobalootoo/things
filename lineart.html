User Guide

This tool converts photos to line art using Sobel Edge Detection. No data leaves your computer.

  • Definition: Lower values catch tiny details; higher values keep only bold outlines.
  • Softness: Use this for "noisy" or grainy photos to prevent messy dots.
  • Line Weight: Thickens the stroke for a marker-pen effect.
